# Batalha Naval

  Acesse o site do jogo!
  ## https://manzatomari.github.io/batalha_naval/

Jogo de Batalha Naval feito em JavaScript, HTML e CSS.

Há três navios de tamanhos diferentes escondidos no tabuleiro: 
um de 4 casas, um de 3 casas e um de 2 casas. 
O objetivo é afundar todos com o menor número de tiros.

## Como jogar

1. Abra o arquivo `index.html` no navegador.
2. Clique em uma casa do tabuleiro para atirar.
3. Cada tiro mostra um resultado: água, acerto ou navio afundado.
4. O jogo termina quando os três navios afundam.

## Arquivos

- `index.html` - estrutura da página
- `batalhaNaval.css` - visual do jogo
- `batalhaNaval.js` - lógica do jogo
- `img/` - imagens usadas no tabuleiro
